# Notion中文模板市场

中国最大的Notion模板分享平台，使用Next.js + Tailwind CSS + shadcn/ui构建。

## 项目特性

- 🎨 简洁现代的设计风格
- 🖼️ 图片优先的模板展示方式
- 📱 响应式设计，支持移动端和桌面端
- 🔍 简单高效的搜索功能
- 📥 模板下载功能
- 🚀 快速轻量级
- 🌐 完全中文化界面

## 自定义配置

### 修改模板数据
编辑 `data/templates.ts` 文件，添加或修改模板信息：
```typescript
{
  id: "template-1",
  title: "模板标题",
  description: "模板描述",
  coverImage: "/images/template-1.jpg",
  category: "productivity",
  subcategory: "project-management",
  downloadUrl: "https://example.com/template-1",
  downloads: 1000,
  rating: 4.5,
  createdAt: "2024-01-15"
}
```

### 修改分类数据
编辑 `data/categories.ts` 文件，自定义分类结构：
```typescript
{
  id: "productivity",
  name: "生产力",
  icon: "⚡",
  subcategories: [
    { id: "project-management", name: "项目管理", count: 45 },
    { id: "time-tracking", name: "时间追踪", count: 32 }
  ]
}
```

### 修改样式
- 主要样式在 `app/globals.css` 中
- 组件样式使用Tailwind CSS类名
- 主题色彩在 `tailwind.config.js` 中配置

## 数据库表结构

### t_templates
模版主表，包含模版的基本信息。

### t_template_images
模版图片表，存储模版的额外图片（除封面外）。
```sql
CREATE TABLE public.t_template_images (
  id bigint generated by default as identity not null,
  template_id uuid null,
  created_at timestamp with time zone not null default now(),
  image_url text not null,
  sort_order smallint null default '0'::smallint,
  constraint t_template_images_pkey primary key (id),
  constraint t_template_images_template_id_fkey foreign KEY (template_id) references t_templates (id)
);
```

### t_template_downloads
模版下载统计表，每个模版一条记录，存储下载次数。
```sql
CREATE TABLE public.t_template_downloads (
  template_id uuid not null,
  download_count integer not null default 0,
  updated_at timestamp with time zone not null default now(),
  constraint t_template_downloads_pkey primary key (template_id),
  constraint t_template_downloads_template_id_fkey foreign KEY (template_id) references t_templates (id) ON DELETE CASCADE
);
```

**注意**：
- 需要在 Supabase 中执行 `supabase/create_template_downloads_table.sql` 来创建下载统计表
- 需要在 Supabase 中执行 `supabase/increment_template_download.sql` 来创建RPC函数（用于原子性更新下载次数）

## 模板提交功能

### 表单字段
- 一级/二级分类（下拉选择）
- 模板名称（必填）
- 功能描述（可选）
- 封面（图片，上传到 Cloudflare R2）
- 模板地址（必填）
- 售价（暂不开放填写）

提交后，将创建 `t_templates` 记录，`status` 为 `pending_review`，并写入 `t_template_categories` 关联所选二级分类。

### API
- `GET /api/categories`：返回所有分类（含父子关系字段）
- `GET /api/templates`：分页检索模板（已支持分类过滤）
- `GET /api/templates/[id]`：获取单个模版详情（包括图片列表、作者信息、下载次数）
- `POST /api/templates`：创建模板（请求体：`title, description, template_url, cover_url, category_id`）
- `POST /api/templates/[id]/download`：记录模版下载次数
- `POST /api/uploads/r2`：生成 R2 直传签名（请求体：`contentType, fileName`）

### Cloudflare R2 环境变量
在运行前配置以下环境变量：

```
R2_ACCOUNT_ID=xxxxxxxxxxxxxxxxxxxx
R2_ACCESS_KEY_ID=XXXXXXXXXXXXXXXX
R2_SECRET_ACCESS_KEY=XXXXXXXXXXXXXXXX
R2_BUCKET_NAME=notion-theme
R2_PUBLIC_BASE_URL=https://cdn.example.com

NEXT_PUBLIC_SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```

说明：
- `R2_PUBLIC_BASE_URL` 为该 R2 Bucket 的公网访问域名，形如 `https://cdn.example.com` 或 `https://<accountid>.r2.cloudflarestorage.com/<bucket>`（建议配 CDN/自定义域）。
- 目前采用服务端签名 + 浏览器直传：先请求签名接口拿到 `uploadUrl`，再以 `PUT` 方式直传文件。

### 使用方式
- 在页面右上角点击「提交模板」打开表单，填写后提交即可。

## 缩略图生成脚本

### 功能说明
用于批量生成模板封面的缩略图，脚本会：
1. 从 Supabase 获取所有模板的 `cover_url`
2. 下载封面图片到本地临时目录
3. 使用 `sharp` 库压缩为缩略图（宽度 400px，保持宽高比，JPEG 质量 80%）
4. 上传到 R2 的 `cover/thum` 目录
5. 更新 Supabase 的 `thum_cover_url` 字段

### 使用方法

```bash
# 使用 npm 脚本运行
npm run generate-thumbnails

# 或直接使用 tsx 运行
npx tsx scripts/generate-thumbnails.ts
```

### 脚本特性
- **智能跳过**：自动跳过已有缩略图的模板和没有封面 URL 的模板
- **错误处理**：单个模板处理失败不会影响其他模板
- **进度显示**：实时显示处理进度和统计信息
- **自动清理**：处理完成后自动清理临时文件

### 环境变量要求
脚本需要以下环境变量（已在 `.env` 中配置）：
- `NEXT_PUBLIC_SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `R2_ACCOUNT_ID`
- `R2_ACCESS_KEY_ID`
- `R2_SECRET_ACCESS_KEY`
- `R2_BUCKET_NAME`
- `R2_PUBLIC_BASE_URL`

## 用户认证功能

### 登录方式
支持四种登录方式：
- **Google 登录**：使用 Google 账号快速登录
- **GitHub 登录**：使用 GitHub 账号快速登录
- **Notion 登录**：使用 Notion 账号快速登录
- **邮箱登录**：输入邮箱地址，系统会发送登录链接到您的邮箱，点击链接即可完成登录

### 功能特性
- 右上角显示登录按钮（未登录时）或用户头像（已登录时）
- 登录后自动跳转回原页面
- 点击头像可查看用户信息和退出登录
- 登录状态持久化，刷新页面后保持登录

### Supabase Auth 环境变量
在 `.env.local` 文件中配置以下环境变量：

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### Supabase 配置步骤
1. 在 Supabase Dashboard 中创建项目
2. 在 Authentication → Providers 中启用以下提供商：
   - Google OAuth（需要配置 Google Client ID 和 Secret）
   - GitHub OAuth（需要配置 GitHub Client ID 和 Secret）
   - Notion OAuth（需要配置 Notion Client ID 和 Secret）
   - Email（默认启用）
3. 在 Authentication → URL Configuration 中配置：
   - Site URL：`http://localhost:3000`（开发环境）或你的生产域名
   - Redirect URLs：添加 `http://localhost:3000/auth/callback` 和你的生产回调地址

### 使用方式
- 点击右上角「登录」按钮进入登录页面
- 选择 Google、GitHub、Notion 或邮箱登录方式
- 登录成功后自动跳转回首页，右上角显示用户头像
